# Change Log

All notable changes to the "copy-code-and-filename" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

- Combine line and column display in one location-format dropdown, with a choice
  to omit columns for complete-line selections while retaining line numbers.
- Reserve `Ctrl+Shift+C` for plain copy while Path Copy mode is enabled and
  remove the separate default relative and absolute path copy shortcuts.
- Add a Settings-only plain-text fallback for complete JSON object selections.
- Add complementary status bar and settings toggles for automatic word fallback
  and Relative Path Copy Mode.
- Add configurable plain-text fallback for partial single-line selections.
- Add configurable trailing newlines to copied code blocks.
- Use longer Markdown fences when selected code contains backticks.
